## Negative controls (exact)

1. anonymous cannot create a seller binding — 401, no row (also `x-seller-id` / `x-admin-key` spoofs on the non-demo runtime → 401/503, no row)
2. seller cannot self-approve — 401, still pending
3. seller cannot approve another seller — 401, still pending
4. seller A cannot cancel seller B's deal — 404, B's draft untouched, no audit row (proved in both new suites)
5. pending seller cannot publish — 409 `seller_kyc_not_approved`, draft kept
6. legacy `/app` is not reached by normal React navigation — zero references, hash-only navigation, root/share/preview never point at `/app`
7. cancel cannot silently behave as pause — live deal stays `PendingTarget` after a refused cancel; paused deal stays `ClosedForJoining` and reopens
8. invalid auth cannot bootstrap a seller — rogue key, expired, anon/service role, wrong issuer, bad subject, unknown kid, non-JWT, anonymous sign-in: no row
9. bonus: a seller token holds no admin authority (admin reads/metrics refused), the bootstrap key cannot approve, a throttled identity cannot draft

## Open / deliberately not done

- A live deal with joins still cannot be cancelled — the financial state machine (`DEAL_TRANSITIONS`, Draft → Cancelled only) is out of this sprint's scope; the UI now explains it and offers pause. Operating path unchanged: pause + deadline.
- `seller_auth.return_to` still carries `/app/seller` — validated by the legacy-owned `safeSellerReturnTo` contract and read by no React code; left alone.
- `/pay/return` and `/pay/cancel` (Grow hosted-payment return pages) link "חזרה לסיטון" to `/app` — inside the Grow integration boundary; unreachable in the pilot (real money 0, no provider redirect).
- `last_login_at` is only written by the cookie login rail, so the admin identity block shows "—" for Supabase logins.
- Hosted verification of the binding needs the deploy (staging Supabase JWTs are ES256 against the project JWKS — the same path the test drives with its own key set).
