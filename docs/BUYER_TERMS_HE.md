# תנאי שימוש לקונה

עסקה קבוצתית ב-Siton היא עסקה שניתן להגיע אליה דרך לינק ישיר או דרך קניון Siton הציבורי. בשני המקרים נפתח אותו דף עסקה קנוני, והזמינות והסטטוס נקבעים רק לפי נתוני המערכת העדכניים.

הצטרפות לעסקה אינה חיוב מיידי. בעת הצטרפות מתבצעת תפיסת מסגרת בלבד. חיוב בפועל יתבצע רק אם העסקה ננעלת ומתקיימים תנאי ההצלחה.

הצלחת העסקה נקבעת לפי חיוב בפועל של לפחות 90% מכמות המינימום. גם אם המינימום הושג לפני חיוב, ההצלחה הסופית תלויה בחיובים בפועל. אם פחות מכך יחויב בפועל, העסקה תיכשל והכספים יטופלו לפי מדיניות ההחזרים.

לפני תפיסת מסגרת יוצגו לקונה מחיר ליחידה, כמות, משלוח אם יש, וסך הכול לתפיסת מסגרת. לא מתבצע חיוב כעת; חיוב בפועל יתבצע רק אם העסקה תיסגר בהצלחה.

לאחר נעילת העסקה לא ניתן לבטל או לשנות כמות דרך המערכת באופן אוטומטי. פניות ביטול, החזר, אי אספקה או מוצר פגום יטופלו דרך support@c-ton.co.il או מול המוכר לפי סוג הבעיה והוראות הדין.

אם העסקה נכשלת, המסגרת משתחררת או חיובים מוחזרים לפי מנגנון המערכת.

המוכר אחראי לאספקת המוצר או השירות, לתיאור, לאיכות, לאחריות ולשירות. C-ton מפעילה את הפלטפורמה, התהליך, הסליקה והמעקב, אך אינה יצרן המוצר ואינה מחליפה את אחריות המוכר.

פרטי אשראי אינם נשמרים אצל C-ton. פרטי הכרטיס מוזנים דרך ספק סליקה מאובטח, ו-C-ton שומרת רק מזהים תפעוליים כגון token או auth id לפי הצורך.

C-ton אינה שולחת הודעות שיווקיות. הודעות למשתמשים הן הודעות תפעוליות הקשורות לעסקה, לאימות, לתשלום, למסמכים, לאספקה או לתמיכה.

השימוש בשירות כפוף לכך שהמשתמש רשאי לבצע את הפעולה לפי דין. אם המשתמש קטין או אינו כשיר לבצע פעולה משפטית, עליו לקבל את הסכמת הוריו או אפוטרופוסו.
