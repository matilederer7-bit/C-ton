# הפעלת צוות הסוכנים — המסלול העדכני

המסמכים המחייבים הם `AGENTS.md`,
`docs/ENGINEERING_OPERATING_SYSTEM.md` ו־`docs/CLOUD_AGENT_MANAGER.md`.

התקנת קובצי הסוכנים אינה מפעילה צוות ברקע. היא מוסיפה עשרה תפקידי מומחה
לשימוש בסביבת Claude שתומכת בהם. המשימות בענן ממשיכות לעבור דרך מנהל
הסוכנים הקיים ב־GitHub, והפנייה הרגילה של הבעלים היא דרך ChatGPT.

1. לאחר סקירה ובדיקות, משלבים את ענף ההתקנה ב־master דרך PR.
2. בודקים הרשאות ומפתחות לפי מדריך ההפעלה ב־`docs/CLOUD_AGENT_MANAGER.md`.
   אין להעתיק מפתחות או סיסמאות לקובצי הריפו.
3. מריצים את בדיקת `Siton Cloud Credential Preflight` הקיימת. הצלחת בדיקת
   הגישה לבדה אינה מוכיחה שסוכן ביצע משימה.
4. שולחים דרך ChatGPT משימת תיעוד קטנה ומוגדרת ובודקים שהיא מגיעה למנהל,
   מפיקה שינוי ובדיקות, נפתחת כ־PR ומחזירה תוצאה למשימה המקורית.
5. מדווחים במפורש מי בנה ומי סקר, אילו בדיקות בוצעו והאם השתתפו שני ספקים.
   רק ריצה בפועל מוכיחה שהצוות פעיל; אחוזי ההפעלה בסטטוס אינם משתנים מעצם ההתקנה.

אין צורך להקים Project נוסף ב־Claude או חמש רוטינות כתנאי להתקנה זו.
הרוטינות בחבילה המקורית היו הצעה, ולא הוכחה לאוטומציות פעילות.
המנהל הקיים נשאר אחראי לענף, לסטטוס, לבדיקות, ל־commit, ל־push ולפתיחת PR
בריצות מנוהלות. סוכני המשנה אינם עוקפים אותו.

להרצה מקומית חוזרת בעותק העבודה הנפרד, עם Node.js ו־Git מותקנים:

```powershell
& "C:\Program Files\Git\bin\bash.exe" "docs/agent-team-bootstrap/install.sh"
```

הגרסה המתוקנת שומרת קבצים קיימים ועוצרת על הבדל אמיתי. אין בה איפוס ענף,
מחיקת תיקיית ההתקנה או העתקת הרשאות אישיות. העבודה המקורית והגיבוי שלה
נשארים במקומם.
